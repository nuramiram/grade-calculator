# Grade Calculator

**Name:** Marron A. Banaglorioso
**Section:** IT3R4

## Description
This is a simple Python program that calculates a student's
average grade based on Prelim, Midterm, and Finals grades.
It displays the average and indicates whether the student
passed or failed.

## How to Run
1. Install Python on your computer.
2. Open a terminal in the project folder.
3. Run: python grade_calculator.py
4. Enter your name and grades when prompted.

## Features
- Accepts three grades.
- Calculates the average.
- Displays PASS or FAIL.
